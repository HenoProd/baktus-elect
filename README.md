# BAKTUS ÉLECT — version premium

Cette version reprend la structure et les informations principales du site fourni, avec une interface plus moderne et responsive.

## Fichiers
- index.html
- styles.css
- script.js

## Mise en ligne GitHub Pages
1. Créez/ouvrez un dépôt GitHub.
2. Ajoutez les 3 fichiers à la racine.
3. Settings → Pages → Deploy from branch → main / root.
4. Ouvrez l'URL GitHub Pages.

Le formulaire de devis prépare automatiquement un message WhatsApp vers +243 996 539 590.

## Logo et visuels
Le logo fourni a été intégré à l’en-tête, à la présentation et au pied de page. Six domaines disposent maintenant de visuels : électricité, solaire, vidéosurveillance, réseaux/VoIP, domotique et climatisation. Les images externes sont des visuels illustratifs et peuvent être remplacées par les photos réelles de l’entreprise.
